How it works

Four agents. One answer you can trust.

Instead of trusting the first AI answer, every task is planned, drafted, audited and repaired until it passes review.

Illustration

The pipeline in motion

1 · Planner

Breaks your task into short, ordered steps so the Executor does not wander.

2 · Executor

Writes the first answer, following the plan. This draft is saved as the initial output.

3 · Critic

Reviews the draft for logic, maths and code errors, and explains every problem it finds.

4 · Fixer

Rewrites the answer using the Critic's feedback. The Critic then checks it again, up to your iteration limit.

Two modes

Self-correcting vs Baseline

Self-correcting runs all four agents in a loop. Baseline is a single Executor pass with no planning or review, so you can measure how much self-correction really helps.

Built-in checks

Reliable, repeatable verification

  • Arithmetic is recomputed with a safe evaluator and compared with the answer.
  • Python code blocks must be syntactically valid.
  • Empty or too-short answers are rejected.
  • A language-model Critic reviews logic and facts on top.
